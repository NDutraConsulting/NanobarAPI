Settings

Runtime controls for this dashboard instance.

Trace capture

Whether EventBusTraceMiddleware records a span for every HTTP request into the eventbus. On by default in this dev app. Turning this off stops new spans from appearing on the Traces page -- it does not delete any already-captured ones.

Refresh cycles

API routes

Re-scans this app's route tree and rewrites nanobar.api-routes.json -- also runs automatically every time the app starts.

Nanobars

Reconciles nanobars against the current route manifest: creates an unclassified placeholder for any declared route with no nanobar yet, and corrects domain on existing ones.

Regression bricks

Drains captured traffic into regression bricks and binds them to nanobars -- the same action as the "Generate bricks" button on the Nanobars page.
